# OPÉRATION SOLDAT

Jeu de stratégie et de gestion de base militaire fictive, en 2D isométrique.

## Lancer le jeu
- Ouvrir `index.html` dans un navigateur récent.
- Aucune installation ni serveur n'est nécessaire.
- Pour publier sur GitHub Pages : créer un dépôt, téléverser tous les fichiers et activer **Settings → Pages → Deploy from a branch → main / root**.

## Fonctionnalités
- Construction de six types d'infrastructures.
- Recrutement et entraînement des soldats.
- Progression jour après jour et production de crédits.
- Missions fictives d'aide humanitaire et de secours.
- Sauvegarde locale dans le navigateur (`localStorage`).
- Interface responsive pour ordinateur et mobile.

## Commandes
1. Choisir un bâtiment dans le panneau « Construire ».
2. Cliquer sur une parcelle libre de la carte.
3. Construire une caserne pour recruter.
4. Construire un centre physique ou de formation pour améliorer les capacités.
5. Passer les journées et débloquer les missions.

## Fichiers
- `index.html` : structure de l'application.
- `style.css` : interface et carte isométrique.
- `game.js` : règles et interactions.

Projet prototype — version 1.0.
